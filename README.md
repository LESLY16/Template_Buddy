# Template Buddy

A sleek browser-based template gallery for launching polished landing pages in seconds. Template Buddy gives you a curated set of modern website concepts—from SaaS startups and creative portfolios to healthcare, fitness, e-commerce, and real-estate layouts—so you can preview, download, and reuse them with ease.

## 🚀 Quick Start

1. Clone or download this repository.
2. Open `index.html` in your browser, or serve the project locally.
3. Choose a template from the dropdown.
4. Preview it instantly and click "Download Code" to save it as an HTML file.

### Local server option

```bash
cd Template_Buddy
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

## 📁 Project Structure

```text
Template_Buddy/
├── index.html      # App shell and controls
├── style.css       # Dark dashboard styling
├── script.js       # Template definitions and interactions
└── README.md       # Project documentation
```

## 🛠️ How It Works

- The app loads a set of HTML template strings from `script.js`.
- The selected template is injected into an `iframe` for instant preview.
- Users can download the generated HTML directly from the interface.
- Each template is self-contained and ready to edit or reuse.
